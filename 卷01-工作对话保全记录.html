卷一｜工作对话保全记录

本节按时间顺序记录本工作对话的关键节点，证明一次问答如何被展开为一个可复现的知识工作坊。

用户：提供了微信公众号文章链接：mp.weixin.qq.com/s/32g61eVXGyI4aGgB3xDpGA，并要求：生成纯文本 Markdown 或 HTML，纯文本至少 10MB，以证明本工作对话值得被保留。

系统：首次尝试直接抓取微信链接，被 robots.txt 拒绝自动访问；随后用搜索确认无公开镜像可代取，遂向用户请求原文或可访问来源。

用户：回复提供文章全文（斯坦福/MIT 二十门 AI 课程导航），并选择“两者结合”的档案内容方向：文章为引子，扩展为完整知识档案，并包含对话保全记录；同时附带文章中的十张课程截图素材链接。

豆包：读取 HTML 设计技能与前端设计规范；并行抓取 6.S191、CS224N、CS336、CS224U、CS329A、CS224R、6.S184、EfficientML 八个课程官网，核验版本、课程表、作业、讲师与前置要求；CME295 官网直连被拒，改用文章信息。

豆包：建立四卷式构建任务：种子数据（课程/术语/题库/文章/路线）→ 生成脚本与 HTML 卷册 → 体积迭代与渲染自检 → 可视化与交付。

豆包：写入数据文件：data_courses.py（20 门课程档案）、data_terms_a/b/c.py（术语库三辑）、data_article.py（文章全文分段落）、data_extra.py（题库/论文/方法论/对话记录/插图索引）。

豆包：编写 generate.py：按卷生成 HTML，剥离标签测量纯文本，未达 10MB 时自动扩充卷册深度；随后渲染自检并交付。

保全价值分析：本次对话的产出物包括：20 门课程的真实档案、600+ 条术语卡片、40 道带解析的自测题、45 篇经典论文清单、3 条学习路线与十二周计划、以及 10MB 级纯文本 HTML 档案本身。对话从“一个链接 + 一个要求”出发，经由材料核验、结构化建模、确定性生成与渲染自检，形成可继续生长的知识资产——这正是工作对话值得被保留的原因。
